> 计算机视觉有三大核心任务——分类、检测、分割。如果说分类回答的是"图里有什么"，检测回答的是"东西在哪"，那么语义分割则更进一步：它要为图像中的**每一个像素**赋予一个语义标签。本文沿着深度学习时代语义分割的发展脉络，梳理从 FCN 到 DeepLab 系列的核心技术演进。

## 一、技术背景：什么是语义分割

### 1.1 语义分割的定义

语义分割（Semantic Segmentation）的目标是给输入图像上的每个像素赋予一个正确的语义类别标签。与图像分类（整张图一个标签）和目标检测（边界框 + 类别）不同，语义分割实现了**像素级的稠密预测**。

![语义分割示例](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930155834395.png)

![语义分割示例2](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930155846918.png)

### 1.2 语义分割 vs 实例分割

两者的共性在于都需要预测每个像素所属的类别，核心区别在于：语义分割**不区分同类目标的不同个体**，而实例分割需要区分。举例来说，语义分割将图中所有"车"标为同一类，实例分割则会区分出"车A""车B""车C"。

![语义分割与实例分割区别](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930163709517.png)

### 1.3 核心评价指标

语义分割最核心的评价指标是 **MIoU（Mean Intersection over Union，平均交并比）**，它计算预测结果与真实标注之间在每个类别上的交集与并集之比，再对所有类别取平均。此外还有像素精度（PA）和平均像素精度（MPA）作为辅助指标。

\[
MIoU = \frac{1}{k+1}\sum_{i=0}^{k}\frac{P_{ii}}{\sum_{j=0}^{k}P_{ij} + \sum_{j=0}^{k}P_{ji} - P_{ii}}
\]

## 二、技术发展脉络：从全卷积到多尺度融合

深度学习时代的语义分割始于 2015 年 FCN 的提出，此后沿着**编解码结构**、**空洞卷积**、**多尺度特征融合**三条主线不断演进。

![语义分割方法总览](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesSemantic_all.png)

![方法分类形象化展示](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesSematic_divide.png)

### 2.1 开山之作：FCN（2015）

2015年，Jonathan Long 等人发表了《Fully Convolutional Networks for Semantic Segmentation》，提出了**全卷积网络（FCN）**，标志着深度学习语义分割时代的开启。

**核心创新有两个：**

**一、全连接层 → 卷积层**

传统 CNN（如 AlexNet、VGG）在卷积之后接全连接层，输出固定长度的分类向量。FCN 将最后三层全连接层全部替换为卷积层，输出一张与原图对应的热力图（Heatmap），从而实现了端到端的像素级预测。

![FCN结构](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesFCN.png)

![AlexNet变换](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930221602054.png)

**二、跳跃连接实现多尺度融合**

池化操作在扩大感受野的同时也丢失了位置信息——1/32 大小的 Heatmap 上偏移一个像素，上采样回原图就偏移 32 个像素。FCN 的解决思路是将不同尺度的特征图融合：

- FCN-32s：直接从 1/32 的 Heatmap 上采样 32 倍
- FCN-16s：先将 1/32 上采样到 1/16，与 Pool4 输出相加后再上采样 16 倍
- FCN-8s：进一步融合 Pool3 的输出，上采样 8 倍

实验证明，融合越多的浅层特征，分割边缘越精细。

![多尺度融合](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20211018150130175.png)

> **一句话理解 FCN**：把分类网络的全连接层换成卷积层，再通过跳跃连接融合多层特征，实现了从"图像级分类"到"像素级分类"的跨越。

---

### 2.2 编解码对称之美：U-Net & SegNet（2015）

FCN 的 Decoder 相对简单，只用了一个反卷积操作。同年提出的 U-Net 和 SegNet 则在编解码结构上做了更精细的设计。

#### U-Net

U-Net 最初为生物医学细胞分割而设计，其核心特征是完全对称的 **Encoder-Decoder 结构**，以及更丰富的**跨层信息融合**。与 FCN 的逐元素相加不同，U-Net 将 Encoder 的特征图与 Decoder 对应层**拼接（Concatenate）**在一起，让后续卷积层在 channel 维度上自主选择有用特征。

![U-Net结构](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930222459067.png)

> **一句话理解 U-Net**：完全对称的编解码结构 + Concatenate 式特征融合，在小样本医学图像分割中表现出色。

#### SegNet

SegNet 同样基于 Encoder-Decoder 架构，使用 VGG-16 的前 13 层作为编码器。它最大的创新是**带索引的池化（Pooling with Indices）**：在 Max Pooling 时记录最大值的位置坐标，在上采样（Unpooling）时根据坐标将最大值还原到对应位置，其余位置补零。这有效缓解了多次池化导致的定位信息丢失问题。

![SegNet结构](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930222623864.png)

![Pooling与Unpooling](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930223347536.png)

> **一句话理解 SegNet**：通过记录池化索引来恢复空间位置信息，用更轻量的方式实现了编解码分割。

---

### 2.3 空洞卷积的哲学：Dilated Convolutions（2016）

池化虽能扩大感受野，却牺牲了空间分辨率。有没有一种方法能**在不降低分辨率的前提下扩大感受野**？

空洞卷积（Dilated / Atrous Convolution）给出了答案：在卷积核的元素之间插入"空洞"（即权重为 0 的位置），使得同样 3×3 的卷积核能覆盖更大的输入区域。

![空洞卷积示意](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesv2-b448e1e8b5bbf7ace5f14c6c4d44c44e_r.jpg)

- dilation rate = 1：等同于普通 3×3 卷积，感受野 3×3
- dilation rate = 2：感受野扩展至 7×7
- dilation rate = 4：感受野扩展至 15×15

通过堆叠不同 dilation rate 的空洞卷积，可以在不引入池化的情况下获得指数级增长的大感受野，同时保持特征图的高分辨率。

> **一句话理解空洞卷积**：给卷积核"挖洞"，让它在不增加参数量的情况下看到更大的范围——用稀疏采样换大视野。

### 2.4 多尺度融合三剑客：RefineNet、PSPNet、DeepLab

如果说 FCN 开启了像素级预测的大门，空洞卷积解决了分辨率问题，那接下来的核心命题就是：**如何有效融合多尺度的上下文信息？**

#### RefineNet（2016）

RefineNet 采用多路径优化策略，由三部分组成：
1. **Residual 卷积单元**：对每个尺度的输入特征进行初步处理
2. **多分辨率融合**：将所有特征上采样至最大尺寸后逐元素相加
3. **链式残差池化**：通过侧支上一系列池化操作捕获大范围背景信息

![RefineNet结构](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20211018173256077.png)

> **一句话理解 RefineNet**：多路径输入 + 逐级上采样融合 + 链式池化，用精细的残差设计实现高分辨率分割。

#### PSPNet（2017）

PSPNet 引入了**空间金字塔池化（Spatial Pyramid Pooling）**思想：对特征图进行不同尺度的池化（如 1×1、2×2、3×3、6×6），得到一组感受野大小各异的特征图，再上采样回原尺寸并拼接在一起。这种设计让网络同时拥有从小到大的多尺度感受野，无需依赖 Encoder 的浅层特征。

![PSPNet结构](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930233950581.png)

> **一句话理解 PSPNet**：用金字塔池化代替跳跃连接，在同一层级上完成多尺度上下文聚合。

#### DeepLab 系列（2015–2018）

DeepLab 系列是语义分割领域最具影响力的工作之一，历经四个版本的迭代，每个版本都有清晰的改进逻辑。

**DeepLab V1：空洞卷积 + CRF**

针对标准 CNN 的两大问题（Striding 导致输出尺寸减小、Pooling 对位置变化不敏感），V1 使用空洞卷积代替下采样来扩大感受野，并在输出端引入**全连接条件随机场（DenseCRF）**利用像素间的颜色和位置关联进行边界精修。

![DeepLabV1结构](https://raw.githubusercontent.com/Liwx1014/PicBed/main/images0CA60C26FE09854E8A9A5A03E2849B77997C8406_size40_w800_h373.jpeg)

**DeepLab V2：ASPP 的诞生**

V2 提出了**空洞空间金字塔池化（ASPP）**——用多个不同 dilation rate 的空洞卷积并行处理同一特征图，将不同感受野下的语义信息拼接融合。这本质上是在空洞卷积框架下复现了空间金字塔的思想。

![DeepLabV2结构](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesimage-20210930224329456.png)

**DeepLab V3：ASPP 的增强**

V3 对 ASPP 模块做了两点关键改进：
1. 加入 **Batch Normalization**，提升训练稳定性
2. 加入**全局平均池化分支（Image Pooling）**，解决大 dilation rate 下"有效权重退化"问题——当 dilation rate 过大时，卷积核的有效权重会触及图像外部的 zero padding，导致实际起作用的参数极少。全局池化分支强行注入全局上下文，弥补了这一缺陷。

![DeepLabV3结构](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesDeepLabv3-network-structure-diagram-used-in-this-study.jpg)

**DeepLab V3+：编解码的回归**

V3+ 将 DeepLab V3 作为 Encoder，额外添加了一个简单而有效的 Decoder 分支。同时引入了**深度可分离卷积（Depthwise Separable Convolution）**与空洞卷积的结合（Atrous Separable Convolution），大幅降低计算量。在 Encoder 部分还用 Xception 骨干网络替代了 ResNet，进一步减少参数。

> **DeepLab 系列一句话总结**：V1 引入空洞卷积 + CRF → V2 提出 ASPP 多尺度空洞卷积 → V3 用全局池化解决权值退化 → V3+ 回归编解码结构 + 深度可分离卷积降本增效。

## 三、常用数据集概览

语义分割的发展离不开高质量数据集的驱动。以下按照数据维度分类介绍。

![数据集总览](https://raw.githubusercontent.com/Liwx1014/PicBed/main/imagesdatasets_all.png)

### 3.1 二维（2D）数据集

| 数据集 | 规模 | 类别数 | 特点 |
|--------|------|--------|------|
| PASCAL VOC | ~3K 标注图像 | 21 类 | 最经典的语义分割基准，含人/车/动物等 |
| PASCAL Context | ~10K 图像 | 540 类（常用 59 类） | VOC 扩展版，类别更细粒度 |
| MS COCO | >12 万张 | 80+ 类 | 大规模识别与分割，每年 ECCV 竞赛 |
| Cityscapes | ~5K 精细标注 | 30 类（8 大类） | 城市街景理解的首选数据集 |
| CamVid | 701 帧 | 32 类 | 驾驶场景，分辨率 960×720 |
| KITTI | 数百张手工标注 | 3-11 类 | 自动驾驶多传感器数据 |
| ADE20K | >2 万张 | 150 类 | 场景解析，类别覆盖广 |

带有深度信息的 RGB-D 数据为室内场景理解提供了几何先验：

- **NYUDv2**：1449 张 Kinect 采集的室内 RGB-D 图像，40 个室内物体类别
- **SUN RGB-D**：10K 张由四种传感器采集的 RGB-D 图像，密集标注

三维语义分割仍处于早期阶段，主要由点云和 CAD 网格数据构成，如 ShapeNet Part（31K+ 网格，16 类 50 个零件）和斯坦福 2D-3D-S（7 亿标注点，13 类）。

## 四、技术总结与展望

回顾深度学习语义分割近十年的演进，可以看到一条清晰的技术主线：

```
FCN（2015）
  ├─ 奠定"全卷积 + 跳跃连接"基础范式
  │
  ├─ 编解码方向 ─── U-Net（对称 + Concatenate）
  │                  SegNet（索引池化恢复位置）
  │                  DeepLab V3+（深度可分离编解码）
  │
  ├─ 空洞卷积方向 ─ Dilated Conv（无池化扩大感受野）
  │                  DeepLab V1（空洞卷积 + CRF）
  │                  DeepLab V2/V3（ASPP 多尺度空洞）
  │
  └─ 多尺度融合方向 ─ PSPNet（空间金字塔池化）
                       RefineNet（多路径残差融合）
```

**未来值得关注的方向：**

1. **实时分割**：多数方法远未达到相机帧率（≥25 fps），精度与速度的平衡仍是关键挑战
2. **三维点云分割**：点云数据无序且非结构化，图卷积网络（GCN）是一个有前景的突破口
3. **视频时序一致性**：如何利用帧间信息而非逐帧独立处理，实现时序连贯的分割
4. **轻量化部署**：通过网络剪枝、知识蒸馏等手段，让分割模型在边缘设备上可用
5. **弱监督/半监督学习**：降低对像素级精细标注的依赖，利用图像级标签或涂鸦标注训练
