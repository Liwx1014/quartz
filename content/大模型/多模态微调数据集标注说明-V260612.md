## 三、数据标注

### 3.1  标注原则

1. **具体而非笼统：** 写"可见按键、显示屏和功能标识"，而不是"一些部件"
2. **区分性强：** 重点描述能将该类别与其他易混淆类别区分开的特征（这里非常重要）
3. **客观描述：** 只描述画面可见内容，不加主观推测

### 3.2  标注步骤

对每张图片，按以下步骤逐一完成标注，确保模型能够学会区分一级类别和具体的二级类别（细分类）：

**Step 1: 确定一级类别归属**

观察图片整体内容，从以下 3 个一级类别中确定归属：

| 一级类别 | 判断标准 |
|---------|---------|
| **标签标识** | 图像主体为标签 / 贴纸 / 铭牌类文本信息，非电饭煲物理结构 |
| **器具外观** | 图像展示电饭煲整体或局部外壳外观，可看到锅身轮廓或外表面 |
| **内部结构** | 图像展示电饭煲内部零部件、电路、线路或结构细节 |

**Step 2: 确定二级类别（细分类别）**

在一级类别下的二级类别列表中，确定最匹配的具体类别。此步骤是细分类任务的核心，需重点对比以下**易混淆类别对**：

| 易混淆类别对 |
|-------------|
| 电路板（正面） vs 电路板（反面） |
| 发热丝 vs 发热盘 vs 发热管末端接线柱 |
| 操作面板 vs 电路板（正面） |
| 器具外观（正面） vs 器具外观（打开状态） |
| NTC vs 感温装置 vs 温控器 |
| 铭牌 vs 能效标签 |
| 电源线入口 vs 电源线夹紧装置 |
| 进线接线端子 vs 发热管末端接线柱 |

**Step 3: 撰写 reasoning（推理依据）**

reasoning 是引导模型建立"图像特征 → 分类结果"推理链的核心字段，需人工基于图像内容撰写，控制在 **100字以内**。

**撰写要求：**
1. **描述关键视觉特征**：包含形状、颜色、材质、位置、上下文环境
2. **突出区分性特征**：重点描述能将该类别与易混淆类别区分开的特征（回到 Step 2 的区分点），回答"为什么是 A 而不是 B"
3. **客观描述**：只写画面中确实可见的内容，禁止主观推测（如"可能"、"应该是"）
4. **禁止出现标签名称**：reasoning 中不得直接出现类别名称（如"这是操作面板"），只描述观察到的视觉特征

> **为什么你要认真标 reasoning？** 训练时，`from=gpt` 的消息是**唯一参与 loss 计算**的部分。笼统的描述（如"一些元件"）会让模型学不到区分性特征；精准的描述（如"绿色PCB裸板上焊接多个IC芯片，元件面朝上"）才能让模型学会"看什么、怎么区分"。你标注的每条 reasoning，本质上是在**教模型如何思考**。

**📋 平台标注字段对应关系**

如果你使用标注平台，各字段填写内容如下：

| 平台字段 | 填写内容 | 对应文档章节 |
|---------|---------|------------|
| `system` | 系统提示词（含 `<image>` 标记） | 参见 [4.3 系统提示词设计](#系统提示词设计) |
| `input` | `请对这张图片进行分类。` | — |
| `output` | reasoning 描述文本 + 一级标签 + 二级标签（空格分隔） | 参见上方 **Step 3: 撰写 reasoning** |

> **output 字段标注示例：**
>
> ```
> 图中仅可见电饭煲操作面板部分，有煮饭和保温按钮及数码管显示区域，未见其他元素  内部结构  操作面板
> ```
>
> 格式说明：`reasoning描述  [空格]  一级标签  [空格]  二级标签`，三部分以空格分隔。

### 4.3 系统提示词设计

>内容如下：每一张图像共用

```
<image>
# 角色
你是电饭煲结构部件质检专家，通过视觉特征识别电饭煲的各种结构部件。

# 类别（共 31 个二级类别，分属 3 个一级）
- 标签标识（2个）：铭牌、能效标签
- 器具外观（6个）：正面、侧面、背面、顶面、底面、打开状态
- 内部结构（23个）：操作面板、锅盖铰链、电源线入口、器具输入插座、电源线夹紧装置、接地、进线接线端子、感温装置、发热丝、发热盘、NTC、热熔断体、温控器、电路板（正面）、电路板（反面）、电路板安装位置、散热风扇、电子元件、发热管末端接线柱、保温发热元件、电机、使用标识、水位标识

# 输出格式（JSON）
{"reasoning": "特征描述(≤100字)", "primary_label": "一级类别", "secondary_label": "二级类别"}

```
