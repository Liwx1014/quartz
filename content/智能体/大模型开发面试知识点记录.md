4.  Memory 作为 Agent 的一个重要模块，如何设计？
Agent 的记忆体系其实参考认识科学里发展而来，分为短期记忆和长期记忆，短期记忆对应的是上下文窗口中的工作记忆，其主要面对的问题是上下文窗口有限怎么办，还有一个 lost in middle，长期以及主要解决的是如何存储、检索、更新问题。

目前短期记忆一般的解决方案第一类是滑动窗口，丢失最旧的消息。第二类摘要总结关键信息。
跨会话的长期记忆，最简单的方式把对话内容保存成 python list, 第二类就是写入 Md 文件集合向量检索，或者是使用知识图谱的方式。但是当面对多租户复杂的 Agent 时，记忆系统需要多种技术配合使用。我最常用的技术就是 congee，他背后使用三种数据库（关系型数据库、向量数据库、图数据库）相互配合使用。关系型数据库作为中央协调者。
1. **关系数据库**（SQLite/PostgreSQL）：存储元数据、用户信息、数据集配置和管道运行状态
2. **向量数据库**（LanceDB/ChromaDB/PGVector）：存储文本块和图谱三元组的向量嵌入，支持语义搜索
3. **图数据库**（Ladybug/Neo4j/Neptune）：存储实体节点和关系边，支持结构化推理
